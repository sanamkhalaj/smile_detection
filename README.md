# Smile Classification

A deep learning project for detecting smiles in facial images.

## Overview

This project uses image processing and deep learning techniques to classify facial images based on whether a person is smiling.

## Technologies

- Python
- OpenCV
- NumPy
- TensorFlow / Keras
- Scikit-learn

## Data Preprocessing

The images are:
- Resized to a fixed image size
- Converted to grayscale
- Shuffled before training
- Prepared for model training

## Model

A neural network model built with TensorFlow/Keras is used for image classification.

## Project Workflow

1. Load the image dataset
2. Preprocess the images
3. Resize and normalize the images
4. Prepare the labels
5. Split the dataset into training and testing sets
6. Train the neural network
7. Evaluate the model

## Results

The model achieved an accuracy of **98%** on the test dataset.
